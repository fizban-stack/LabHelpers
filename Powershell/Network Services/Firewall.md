# New Firewall Rule
```powershell
New-NetFirewallRule
```
# Set Firewall Rule Properties
```powershell
Set-NetFirewallRule -DisplayGroup "Remote Access" -Enabled True
```
# Display Firewall Rule Properties
```powershell
Get-NetFirewallRule
```
# Delete Firewall Rule
```powershell
Remove-NetFirewallRule
```

# Rename Firewall Rule
```powershell
Rename-NetFirewallRule
```
# Copy Firewall Rule
```powershell
Copy-NetFirewallRule
```
# Enable Firewall Rule
```powershell
Enable-NetFirewallRule
```
# Disable Firewall Rule
```powershell
Disable-NetFirewallRule
```
# Display Firewall Profile Properties
```powershell
Get-NetFirewallProfile
```
# Set Firewall Profile Properties
```powershell
Set-NetFirewallProfile
```
